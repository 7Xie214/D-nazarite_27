# 前舵零位保持实施计划

目标：ChassisTask 独立保持左前/右前 GM6020 的已标定机械零位。

1. tests 新增真实任务/APP/Device/算法集成用例，确认旧实现被其余六轴反馈门槛阻塞。
2. ChassisApp.c 从已有 read_feedback 提取舵向反馈换算，新增仅两台前舵的保持更新，
   目标固定零、每轴独立复位/恢复、沿用既有限角与电压限幅；头文件声明入口。
3. Chassis_Conf.h 增加行走模式选择，ChassisTask 默认执行零位保持，行走模式保留
   原有通知/到位流程。My_task.c 不写入 GM6020，不改上楼动作。
4. PID_Config.c 配置 FL/FR 舵向 P/P 试调参数和速度限幅，保持其余配置不变。
5. 运行新集成测试 O0/O2、原 APP/任务模式测试、相关上层运动回归及 Keil 编译链接。
   记录实际结果并说明真实零偏与增益仍需实机标定，不自动烧录或提交。
